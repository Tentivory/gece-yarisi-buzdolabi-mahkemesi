# Gece Yarısı Buzdolabı Mahkemesi

Bu depo, insanlık tarihinin en az tartışılan ama en çok ihtiyaç duyulan yargı organını belgeler:
**buzdolabını gece yarısı açtığın anda kurulan fiili mahkeme.**

## Misyon

Artık yemeklerin adil yargılanmasını sağlamak.
Kamuoyunu (yani seni) vicdan azabından kısmen kurtarmak.
Bilimi ilerletmemek.

## Kurulum

```bash
python3 mahkeme.py
```

Başka bir şey gerekmez. Avukat da gerekmez. Çünkü zaten kaybedeceksin.

## Yargılama Usulü

1. Buzdolabı kapağı açılır.
2. Işık yanar (tanık).
3. Bir yiyecek rastgele sanık sıfatıyla seçilir.
4. Hüküm okunur.
5. Sen yine de o yiyeceği yersin ya da yemezsin. Mahkeme umursamaz.
